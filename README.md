# الميزان — ميزان تربوي

منصة توثيق أعمال الأقسام وإنتاج «تقرير أعمال القسم» الدوري، مع لوحة متابعة خاصة بالنائب الأكاديمي.
مدرسة الشيماء الثانوية للبنات — 2026-2027.

## كيف تعمل

- **الواجهة** (هذا المستودع) صفحات ثابتة على GitHub Pages، ولا تحتوي أي بيانات حقيقية أو أرقام سرية.
- **الخادم** ملف `apps-script/Code.gs` يعمل في حساب Google الخاص بالنائب الأكاديمي.
  - يقرأ ويكتب في جدول «الميزان — قاعدة البيانات».
  - يتحقق من الأرقام السرية على الخادم فقط.
  - يحفظ التوقيع في مجلد Drive خاص.
- إذا كان `js/config.js` فارغاً تعمل المنصة في **وضع المعاينة** ببيانات وأسماء خيالية.

## التشغيل لأول مرة (مرة واحدة)

1. افتحي https://script.google.com وأنشئي مشروعاً جديداً باسم «الميزان».
2. احذفي محتوى `Code.gs` والصقي محتوى الملف `apps-script/Code.gs` كاملاً، ثم احفظي.
3. من القائمة العلوية اختاري الدالة `setup` واضغطي **تشغيل** (Run).
   - وافقي على الصلاحيات المطلوبة: Sheets وDrive.
4. اضغطي **نشر ← نشر جديد** (Deploy → New deployment)، ثم اختاري النوع **تطبيق ويب** (Web app)، واضبطي الإعدادات كالتالي:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخي رابط تطبيق الويب (ينتهي بـ `/exec`) وضعيه في `js/config.js`.

## الأدوار

- **المنسقة**:
  - تدخل برقمها السري، وترى قسمها فقط.
  - توثّق البنود الخمسة عشر، فيُكتب التقرير تلقائياً.
  - توقّع برقمها السري، فتُقفل سجلات الفترة.
- **النائب الأكاديمي**:
  - لوحة خاصة فيها: مقارنة الأقسام، ولوحات التميز، واعتماد التقارير بتوقيعها، وخطة زياراتها للمعلمات.
  - تُقرأ نتائج سنابل من متصفحها للقراءة فقط.
